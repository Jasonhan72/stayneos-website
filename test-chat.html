This is set in wrangler.toml for development. For production, update to the actual Gateway URL.

Testing Instructions

  1. Run the Next.js development server: npm run dev
  2. Visit any page on the website
  3. Look for the blue chat button in bottom-right (left of WhatsApp)
  4. Click to open chat window
  5. Test sending messages
  6. Check browser console for any errors

Note: If OpenClaw Gateway is not running, the chat will use fallback responses.

Fallback Responses

When OpenClaw Gateway is unavailable, these responses will be used:

  • "Hi! I'm Aria, NEOS Customer Care. How can I help you today?"
  • "For booking inquiries, please visit our properties page or use the AI concierge above."
  • "For urgent matters, you can WhatsApp us at +1 647 862 6518."
  • "Our team typically responds within 2 hours during business hours (9am-6pm EST)."

i18n Support

All UI text is translatable with keys added to:

  • messages/en.json (English)
  • messages/fr.json (French)
  • messages/zh.json (Chinese)
